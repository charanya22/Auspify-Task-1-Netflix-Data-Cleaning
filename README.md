## 📌 Project Overview

This project cleans and analyzes Netflix data using Python, Pandas, and Streamlit.

**Internship:** Auspify Technologies  
**Domain:** Data Analysis Using Python

## 🎯 Objective

Clean and inspect a Netflix titles dataset using Python and Pandas.

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Plotly

## ✨ Features

- Dataset inspection
- Missing-value and duplicate checks
- Text-field cleaning
- Date processing
- Interactive dashboard
- Cleaned CSV download

## 📂 Dataset

The dataset contains Netflix movie and TV show information, including title, director, country, release year, rating, and duration.

## ▶️ Run the Project

Install the required packages:

```bash
pip install pandas streamlit plotly
```

Start the dashboard:

```bash
python -m streamlit run app.py
```

## 📊 Output

The dashboard displays data-quality information, content-type charts, a data preview, and an option to download the cleaned dataset.
